## True data provenance

- **Primary data**: `datasets/ana/logscope_ana_1200_pencere_ozellikleri.csv` and distinct minute truth CSV, derived from a fully OFFLINE 8-scenario statistical simulation.
- Source provenance is explained in `datasets/ana/README_VERI_KARTI.md`.
- **Primary evaluation**: 720 train windows (seeds 11, 23, 42); 240 calibration (seed 71); 240 untouched test (seed 97). Chronological and seed-disjoint. Normal-only train, normal-only threshold calibration.
- **Secondary evaluation**: five independently seeded synthetic runs from the older `synthetic_windows` generator; each 60/20/20 chronological. This is a DIFFERENT generator, NOT five bootstraps of the primary source. It exposes severe transfer instability for Isolation Forest. Do not suppress these results.
- Features: the same ten numerical minute-window signals used by B0 multivariate, K-Means, DBSCAN and Isolation Forest. The original B0 single-volume control is included separately. The target label and scenario/seed/split IDs are not model features.
- We use .05 validation-normal FPR target and report realized test FPR. .10 is a predeclared sensitivity analysis, not a test-time optimized threshold.
- A no-rare-route feature ablation is presented explicitly because route rarity was unusually predictive in this simulator.

## Conclusions, without cherry-picking

- On the primary OFFLINE held-out seed 97, multivariate B0, K-Means and DBSCAN clear 0.80 F1. Isolation Forest is also strong on this source, but does not reproduce across the alternate synthetic generator.
- The single-feature B0 is uninformative for anomaly modes driven by errors, latency, rare routes and failed logins. It may return F1 zero by design; do not conceal this baseline.
- Raw source traffic is statistically simulated and must NEVER be described as Django/Locust-generated real HTTP.
- No real-world HTTP attack accuracy is validated by this deliverable. Prior ModSec-WP scores from other notebooks are separate request-level results and cannot be mixed with minute-window numbers.
- No metrics are computed for unlabeled real web server logs.

## What to tell the instructor

We have corrected the comparison protocol and held the test out from fitting and threshold choice. We compared the volume-only Robust Z baseline against multivariate Robust Z, K-Means, DBSCAN and Isolation Forest on identical minute features. The primary offline source shows that the old 0-F1 baseline was a feature-coverage problem rather than proof that Robust Z is intrinsically ineffective. A second offline simulation generator reveals that Isolation Forest is sensitive to the source distribution, so we are not claiming production-grade generalization. In Week 5 the React Model Centre reads the verified comparison through an authenticated FastAPI endpoint. Live Locust and full production React build remain acceptance tasks.
