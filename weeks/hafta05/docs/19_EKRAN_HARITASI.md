## Temel tıklama akışları

- **İlk keşif:** Tanıtım → Fiyatlandırma → Kayıt → İlk kurulum → Entegrasyonlar → Veri kaynakları → Genel bakış.
- **Alarm analizi:** Genel bakış → Alarm merkezi → Alarm detayı → İnceleme notu / karar.
- **Takım yönetimi:** Genel bakış → Ekip ve yetkiler → Demo kullanıcı ekleme ve rol değiştirme.
- **Bildirim:** Genel bakış → Bildirim merkezi → Alarma git → Alarm detayı.
- **Yardım:** Panel → Yardım merkezi → İlgili kılavuz → Uygun ürün ekranı.
- **Abonelik:** Panel → Abonelik ve faturalandırma → Fiyatlandırma (gerçek ödeme bulunmaz).

**Ayrım:** Figma prototipi gezinilebilir ekran bağlantılarıdır. Site HTML sürümü bazı etkileşimleri ve örnek alarm/veri işlevlerini simüle eder. Tam bir üretim SaaS sistemi değildir.
