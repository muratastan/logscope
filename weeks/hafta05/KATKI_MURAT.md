# Murat - Hafta 5 React ve ara demo katkisi

Bu paket, mevcut GitHub deposunun kokune cikartilmak icin hazirlanmistir.

Kapsam: React arayuzu ve alti ekranlik demo akisinin kodlari, sayfa tasarimlari, HTML onizleme, kurulum ve arac konfigurasyon dosyalari ile Turkce dokumanlar.

Bu dosyalarin her birini gozden gecirip arayuz derlemesini kontrol ettikten sonra kendi GitHub hesabinizdan ayrica commit ve PR olusturun. Backend ilk PR ile main'e alindiktan sonra bu paketi ekleyin.

Birlesik calistirma adimlari icin LogScope_Hafta05_Iki_Kisi_GitHub_Rehberi.md dosyasini kullanin.
