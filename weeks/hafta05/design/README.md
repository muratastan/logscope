# Hafta 2 — LogScope UI / mockup paketi

Bu klasörde altı temel ekranın ayrı SVG tasarımı ve PNG önizlemesi yer alır:
Giriş, Genel Bakış, Trafik, Model Merkezi, Alarmlar, Alarm Detayı.

- `figma_svg/` — Figma'ya aktarılabilir vektör kaynakları (otomatik olarak Figma Design katmanlarına dönüşmez).
- `previews/` — maketlerin kontrol görselleri.
- `../frontend/` — aynı ürünün React kaynak kodu (toplam 19 yönlendirilebilir ekran).
- `../prototip/19_Ekran_Calisan_Demo.html` — derleme olmadan açılan site demosu.

Mevcut Figma tasarım dosyası (13 ekran oluşturulmuş):
https://www.figma.com/design/kIRsA8TcwvZBXdt3IeBIWB

**Figma içindeki prototip bağlantıları doğrulanmış değildir.** Sayfalar arası çalışan geçişleri React/HTML demosu ile gösterebilirsiniz. Dersi değerlendiren kişiye bunu Figma prototipinde uygulanmış gibi söylemeyin.
